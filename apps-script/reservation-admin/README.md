# 星空フォト予約管理（Google Apps Script）

Googleスプレッドシート「星空フォト予約管理」をデータベースとして使う、スタッフ専用の予約管理Webアプリです。

## ファイル

- `Code.gs`: 予約文の解析、保存、重複確認、LINE文章生成
- `Index.html`: スタッフ用Web画面
- `appsscript.json`: Apps Script設定

## 運用

1. 公式LINEに届いた予約内容を「予約を取り込む」へ貼り付ける
2. 読み取り結果を確認する（撮影希望日・希望時間帯・プラン・名前・参加者の性別内訳・携帯番号・深夜料金同意が必須）
3. 月齢・星の位置・空き状況を確認し、24時間・1分単位で確定時間を1つ選ぶ
4. 「保存して確定文をコピー」で、予約枠の確保・予約保存・確定文コピーを同時に行う
5. 予約一覧から確定時間・集合場所・ステータスを更新する
6. 当日に集合場所を入力し、当日案内文をコピーする

確定した撮影枠は「撮影枠」シートへ同期され、同じ日・同じ時間の重複予約は保存時に停止します。

## Googleカレンダー連携

確定した予約（確定時間あり・キャンセル以外）は、スタッフ共有のGoogleカレンダーへ自動でイベント登録されます。予約の変更で日時・内容が更新され、キャンセルでイベントが削除されます。

### 初回セットアップ

1. Apps Scriptエディタで `setupSharedCalendar` を実行する（専用カレンダー「星空フォト予約」が作成され、設定シートのG2にIDが自動入力される）。既存のカレンダーを使う場合は、そのカレンダーIDを設定シートのG2に直接貼り付ける
2. 初回実行時にカレンダーへのアクセス許可を求められるので承認する
3. Googleカレンダー側の設定で、カレンダーをスタッフのGoogleアカウントへ共有する（「予定の変更」権限）
4. 既存の確定済み予約もカレンダーに載せたい場合は `syncAllReservationsToCalendar` を1回実行する

- 0〜5時台の確定時間は、撮影日の夜が日をまたいだ深夜帯として翌日の日時で登録されます
- イベントの長さは既定で60分（`CALENDAR_CONFIG.eventMinutes` で変更可能）
- カレンダー登録に失敗しても予約の保存は成功します。失敗時は画面に警告トーストが出て、操作ログに記録されます
- 予約データシートに「カレンダーイベントID」列（29列目）が自動追加されます
