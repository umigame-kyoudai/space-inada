## 日々の管理

予約対応は、公式LINEで受信 → 予約管理アプリに取り込み → 確定時間を保存 → 確定文をLINEで送信 → 当日案内、の流れ。詳細は [予約管理README](../apps-script/reservation-admin/README.md) を参照。

サイトの更新は現在、コード内のデータ編集方式。ブラウザの入力フォームから記事や写真を管理するCMSを引き渡す構成ではない。いなちゃん本人、または本人が依頼する担当者が次のファイルを更新できる必要がある。管理画面を新設する場合は別途要件を決める。

| 更新内容 | 編集箇所 |
| --- | --- |
| プラン・料金 | `src/data/plans.ts`。予約管理アプリ側の価格・オプションとの整合も確認 |
| ブログ | `src/data/posts.ts` |
| 写真・動画 | `public/images/`、`public/videos/`、`src/data/images.ts` |
| FAQ・お客様の声 | `src/data/faqs.ts`、`src/data/testimonials.ts` |

通常の更新は、変更用ブランチで編集 → `npm run lint` / `npm run build` → HTTPSプレビューをスマホで確認 → `main`へ反映 → 本番確認。移管後のプレビューURLと実際の公開操作をこの資料に追記する。

休止日カレンダーは現時点で2026年限定。2027年の予約受付前に、年と休止日を確認・更新する。現行の予約カレンダー表示はリアルタイムの満席管理ではなく、予約の確定はLINEで行う。

## 移管時に注意する依存

- Google Driveはアカウント種別により組織外への所有権移管ができない。メールアドレスだけで可否を確定せず、移管元・先の種別と制約を確認する。[Google公式](https://support.google.com/drive/answer/2494892)
- Apps Scriptはプロジェクトの所有者を変えても、既存の版付きデプロイの所有者は変わらない。今回、本人アカウントで稼働しているとの回答があるため、まず公開実行者と台帳への接続を照合する。旧管理者のデプロイが残っている場合に限り、本人による公開・認可が必要かを確認する。[Google公式](https://developers.google.com/apps-script/concepts/deployments)
- GitHub移管後も連携・秘密値等が残るため、Cloudflare接続や旧Vercel連携を個別に確認する。[GitHub公式](https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository)
- Cloudflareへのドメイン登録移管には、Cloudflare側で有効なゾーン、移管条件の確認、料金確認などが必要。[Cloudflare公式](https://developers.cloudflare.com/registrar/get-started/transfer-domain-to-cloudflare/)
- Cloudflareの確認用ビルドは `NEXT_PUBLIC_DEPLOYMENT_STAGE=preview` によりGA4を無効化し、検索登録を除外する。本番切替ではこの設定を見直す。
